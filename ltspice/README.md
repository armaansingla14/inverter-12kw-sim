# LTspice netlists (not run here)

LTspice-syntax versions of the two power stages, for interactive inspection in
LTspice. They were **not simulated** in this repository (LTspice is not
available in the build environment); all reported numbers come from the Python
simulators and the ngspice cross-check decks generated by `invsim/spice.py`.

- `inverter_3ph_spwm.cir` - 12 kW three-phase inverter, sine-triangle PWM with
  dead time, LC filter, star resistive load, IGBT-like switches with
  antiparallel diodes.
- `boost_2ph_interleaved.cir` - two-phase interleaved boost, 400 V to 700 V.
